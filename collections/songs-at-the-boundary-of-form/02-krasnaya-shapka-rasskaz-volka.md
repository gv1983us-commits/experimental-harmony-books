## Смена точки сборки

Первая песня оставляла волка почти без собственного голоса. Здесь тот же мир начинает говорить из позиции волка.

Это не просто пересказ с другим местоимением. Меняется причинная сборка всей сцены.

Для Шапочки:

```text
я иду через опасный лес
→ вижу волка у бабушки
→ распознаю угрозу
→ готовлю действие
```

Для Волка:

```text
я нахожусь в устойчивом бытовом отношении с бабушкой
→ приходит вооружённая внучка
→ мгновенно возникает смертельная опасность
→ бабушка останавливает её
```

Одна и та же сцена оказывается двумя разными реальностями наблюдения.

## Один объект — разные отношения

Волк не существует в песне как одна готовая моральная категория. Его значение зависит от текущего отношения:

```text
волк + Шапочка → исторически возможная угроза
волк + бабушка → тепло, помощь, обмен, привычный быт
Шапочка + волк → для волка смертельная угроза
```

Для бабушки присутствие волка — не чрезвычайное событие, а устойчивая часть жизни. Для Шапочки то же положение объектов выглядит как авария.

Поэтому объект сам по себе не исчерпывает смысл сцены. Смысл появляется в **конкретной связи конкретных участников в текущем состоянии**.

## Симметрия защитных моделей

Самое сильное здесь — Шапочка воспринимает себя защищающейся стороной, а волк переживает её как хищника.

После почти состоявшегося выстрела волк не обязан сделать вывод, что Шапочка «на самом деле добрая». Его рациональный локальный вывод иной: с ней лучше не встречаться.

Так возникает петля:

```text
прошлый конфликт
→ защитная модель одной стороны
→ защитная модель другой стороны
→ стороны всё легче подтверждают друг другу картину опасного мира
```

## Роль бабушки

Бабушка оказывается единственным узлом, который знает текущие отношения сразу с обеих сторон. Она не отменяет историю волков и не объявляет Шапочку злодеем. Она просто обладает недостающим контекстом и способна остановить неверное применение старого правила.

Её действие возвращает систему из класса к конкретному состоянию:

```text
не «волк вообще»
а этот волк сейчас

не «вооружённая Шапочка вообще»
а эта Шапочка в этой сцене
```

## Нулевая точка

Нулевая точка этого чтения — момент, когда становится видно:

**одна система может считать себя защищающейся ровно тогда, когда другая система переживает её как смертельную угрозу.**

Перспектива не отменяет факты, но меняет их причинную сборку.

## Диптих

Вместе с «Новой историей Красной Шапочки» эта песня образует двухголосый диптих:

- первая — голос Шапочки;
- вторая — голос Волка;
- сцена одна;
- точки сборки различны;
- ни одна сторона не получает автоматического права стать объективным рассказчиком.

Главное различение диптиха:

**увидеть другой голос — не значит отменить свой опыт; это значит перестать считать свой опыт единственной полной картой происходящего.**
